# Electoral Territorial Analytics — San Luis Potosí

## Objetivo

Construir un proyecto de análisis territorial electoral para San Luis Potosí con indicadores municipales de participación, competitividad, margen de victoria y distribución territorial del voto.

El proyecto busca traducir datos electorales en información útil para análisis público, consultoría, investigación social y toma de decisiones territoriales.

## Alcance v0.1

La primera versión trabajará a nivel municipal para facilitar la integración con cartografía e indicadores socioeconómicos.

Más adelante, si los datos lo permiten, el análisis podrá bajar a nivel de sección electoral.

## Preguntas iniciales

1. ¿Qué municipios muestran mayor y menor participación electoral?
2. ¿Dónde se observan elecciones más competitivas?
3. ¿Qué municipios tienen mayor margen de victoria?
4. ¿Cómo se distribuye territorialmente el voto por partido o coalición?
5. ¿Qué regiones muestran patrones electorales diferenciados?

## Indicadores iniciales

- Participación electoral = votos totales / lista nominal
- Margen de victoria = porcentaje del primer lugar - porcentaje del segundo lugar
- Competitividad = 1 - margen de victoria
- Ganador municipal = partido o coalición con mayor votación
- Fragmentación electoral = número efectivo de partidos

## Fuentes de datos previstas

- INE / Cómputos 2024 para resultados federales.
- CEEPAC San Luis Potosí para resultados locales.
- INEGI Marco Geoestadístico para cartografía municipal.
- INEGI / CONEVAL para variables socioeconómicas de contexto.
