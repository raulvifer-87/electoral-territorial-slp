# Data Sources

## Electoral data

### INE - Cómputos 2024
Uso previsto: resultados federales oficiales de 2024.

### CEEPAC San Luis Potosí
Uso previsto: resultados locales de ayuntamientos y diputaciones locales 2024.

## Geographic data

### INEGI - Marco Geoestadístico
Uso previsto: cartografía municipal para construir mapas territoriales.

## Socioeconomic data

### INEGI / CONEVAL
Uso previsto: variables de contexto como población, pobreza, ruralidad, rezago social, escolaridad y acceso a servicios.

## Nota metodológica inicial

El proyecto inicia con escala municipal porque permite construir indicadores territoriales claros y unir resultados electorales con cartografía municipal. Una dificultad esperada es armonizar municipios electorales 2024 con cartografía actual, especialmente por la creación reciente de Villa de Pozos.
